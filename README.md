# Собеседование кладовщика РЦ — У Михалыча

Комплект для подбора на вакансию кладовщика распределительного центра.

## Ссылка для коллег

**https://arimberg-svg.github.io/kladovshchik-rc-interview/**

Открывается в браузере, без входа в GitHub. Кандидатам ссылку не отправлять: внутри ключи теста и вопросы про судимость и алкоголь.

Репозиторий: https://github.com/arimberg-svg/kladovshchik-rc-interview

## Как проводить

1. Встреча ~45 минут.
2. Телефон у кандидата забрать.
3. Печать бланка — кнопка «Печать бланка» (ключи на печать не попадут).
4. 18 минут на письменный тест.
5. Проверить блоки 1–2 по ключам. Проход: **19 из 26**.
6. 10 устных вопросов. Пункты 5 (судимость) и 6 (алкоголь) — всем, прямо, сверять с анкетой.

## Что в файле

- Бланк кандидату: внимательность, регламент РЦ, честность, судимость, алкоголь, мотивация
- Ключи теста
- 10 вопросов на собеседование с хорошими / плохими ответами
- Лист решения: берём / стажировка / отказ

Ключи взяты из инструкций РЦ: приёмка, перемещения, сроки годности, статья «Кража», ДИ кладовщика.
